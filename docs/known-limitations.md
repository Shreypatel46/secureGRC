# Known Limitations

## Eramba Dashboard — Worker Cron on Windows Docker Desktop

**Status:** Known platform limitation  
**Impact:** Eramba's built-in dashboard does not load  
**Root cause:** Eramba's Worker cron job cannot resolve the PUBLIC_ADDRESS
callback URL when running on Windows Docker Desktop. This is a confirmed
known issue on Eramba's official forum (discussions.eramba.org/t/6065).
The Eramba team has not released a Windows Docker fix as of v3.30.0.

**Workaround implemented:** SecureGRC's custom HTML compliance dashboard
(`reports/grc_dashboard_report.html`) provides equivalent and superior
reporting — generated by `automation/dashboard.py` using live CVE data,
BRS scores, and ISO 27001 control audit results.

**Production note:** In a production Linux deployment, set PUBLIC_ADDRESS
to the server's FQDN and the Worker cron resolves correctly.
